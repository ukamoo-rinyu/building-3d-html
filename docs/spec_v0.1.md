## 1. 目的と背景

「大阪市営住宅3Dマップ」（GitHub: ukamoo-rinyu/osaka-shiei-jutaku-3d）は、PLATEAUの建物形状と高さを使い、市営住宅の住棟だけを立ち上げたウェブ3Dマップである。作成はすべて手作業のスクリプトで行い、次の工程を踏んだ。

1. PLATEAU（CityGML）から建物の形と高さを取り出す
2. 住宅の位置（点）と建物を重ねて照合する
3. 照合ミス（同じ建物に点が2つ、細長すぎる建物など）を確認用HTMLで手作業で直す
4. MapLibre GL JS で、建物を高さで立ち上げた単一HTMLを作る

この工程をQGISプラグインにまとめ、**市営住宅以外の施設でも同じ3Dマップを作れるようにする**。照合ミスの修正はQGISが得意な作業なので、確認用HTMLを毎回作る必要がなくなる。

既存の「Map to HTML」シリーズ（2D地図をLeafletでHTML出力）の3D版として位置づける。

## 4. ダイアログ（入力項目）

1画面で完結させる。上から順に設定し、最後に「書き出す」を押す流れにする。

| 項目 | 入力方法 | 既定値・補足 |
| --- | --- | --- |
| 建物レイヤ | 面レイヤのプルダウン | レイヤパネルで選択中の面レイヤ |
| 対象 | 「全件」「選択中の地物のみ」 | 選択があれば「選択中のみ」 |
| 高さの列 | 数値列のプルダウン | 列名に height / 高さ / measuredHeight を含む列があれば自動選択 |
| 高さが空のとき | 数値入力（m） | 10。空・0・負の値に使う。使った件数を完了時に報告する |
| 高さの強調 | 倍率（1〜5倍） | 1。HTML側でも切替できるようにする |
| 表示名の列 | 列のプルダウン | クリック時の見出しに使う |
| 詳細に出す列 | チェックリスト | 全列。並び順はレイヤの列順。各列に別名（パネルに出す項目名）を入力できる。空欄なら列名のまま |
| 色 | 「QGISのスタイルに合わせる」「単色」 | QGISのスタイル |
| 背景地図 | 淡色地図／航空写真／なし（チェックで複数可） | 淡色＋航空写真、初期表示は淡色 |
| タイトル | 文字入力 | レイヤ名 |
| 出力先 | ファイル保存ダイアログ | 前回の出力フォルダ |

件数が多いときは書き出し前に警告する（しきい値は1万棟）。完了時は出力件数・高さを補った件数・ファイルサイズを表示し、「ブラウザで開く」ボタンを出す。前回の設定はレイヤごとに保存して次回に復元する。

## 5. 処理の流れ

「レイヤ→GeoJSON→テンプレートに埋め込み→1ファイル出力」の一直線とする。

1. **地物を集める**：対象（全件／選択中）の地物を取り出す。マルチポリゴンはそのまま扱い、ジオメトリが壊れている地物は除外して件数を報告する。
2. **座標を変換する**：レイヤのCRSから EPSG:4326 へ変換する。座標は小数6桁（約10cm）に丸めてファイルを軽くする。
3. **高さを決める**：高さの列の値を `H` として持たせる。空・0・負の値は既定値で補い、補った地物に `Hfill=1` の印を付ける。
4. **属性を絞る**：表示名の列と「詳細に出す列」だけを残す。地物には連番のIDを振る（MapLibre の選択表示で使う）。列の別名は設定として別に持たせ、パネルの表示にだけ使う（GeoJSONの列名は変えない）。
5. **色を読む**（`style_reader.py`）：レイヤのレンダラーから各地物の塗り色を決め、`C`（#rrggbb）として持たせる。
   1. 単一シンボル・分類（カテゴリ）・段階（グラデーション）・ルールベースに対応する。
   2. 地物ごとに「どのシンボルが当たるか」を QGIS 自身に判定させ（`symbolsForFeature` 等）、その塗り色を取る。判定をJS側で再現しない。
   3. 凡例用に、分類名と色の一覧も別に持たせる。
   4. Map to HTML の QgsSymbol→JSON の仕組みに流用できる部分があれば流用する。
6. **組み立てる**（`html_builder.py`）：テンプレートの置き換え箇所に、GeoJSON・凡例・設定（タイトル、背景、初期表示範囲など）・MapLibre の JS と CSS を埋め込む。
   1. 埋め込むJSON内の `</` は `<\/` に置き換える（scriptタグが途中で閉じるのを防ぐ）。
   2. 初期表示範囲は出力した地物全体が収まる範囲とする。
7. **保存して報告する**：UTF-8 で保存し、完了画面を出す。

## 6. 出力HTMLの仕様

市営住宅3Dマップ（index.html）の見た目と操作を基準にする。迷ったらそれに合わせる。

**地図**

- MapLibre GL JS の `fill-extrusion` レイヤで建物を立ち上げる。高さ＝`H`×強調倍率、色＝`C`。
- 建物の輪郭線を細く描き、隣り合う建物の境目が分かるようにする。
- 高さを補った建物（`Hfill=1`）は半透明にして区別する。
- 初期表示は3D（傾き55°）、北を上に固定する（回転させない）。

**操作**

- 右上に「2D／3D」切替ボタン。2Dは真上から、3Dは傾き55°。
- 高さの強調（1倍／3倍など）の切替。
- 背景地図の切替（地理院タイル 淡色地図・航空写真）と、背景の濃さ（初期35%）のスライダー。
- 凡例（色分けの一覧）を左下に表示。たたむ／ひらくができ、項目が多いときは高さを画面の半分までにしてスクロールで全件を見せる（§9）。

**詳細パネル**

- 建物をクリックすると、右側のパネルに表示名と詳細の列を表で出す（項目名は§4の別名を使う）（ポップアップは使わない）。
- 選択中の建物は色と輪郭で強調する。もう一度クリックか「閉じる」で解除。
- パネルは「たたむ／ひらく」ができる。

**その他**

- 出典表示：「地理院タイル」「PLATEAU（国土交通省）」など。PLATEAUの表記は、ダイアログでオン・オフできるようにする（PLATEAU以外のレイヤにも使うため）。
- PCのブラウザ（Edge・Chrome）を主な対象とする。スマホでも崩れない程度の配慮はするが、最適化は不要。
- ライト／ダークは閲覧環境に合わせて自動で切り替える。

## 7. 制約と注意点

- **庁内環境**：ソフトのインストールとネットワークに制限がある。プラグインは Python 標準ライブラリと QGIS（PyQGIS）だけで動かし、pip で追加のパッケージを入れない。
- **オフラインで開ける**：MapLibre の JS・CSS は CDN から読まず、`vendor/` からHTMLに埋め込む。ネットが必要なのは背景の地理院タイルだけとし、つながらないときは背景なしで建物だけ表示されること。
- **1ファイル完結**：出力は `.html` 1個。共有フォルダに置いてダブルクリックで開ける形にする。
- **ファイルサイズ**：MapLibre 本体だけで約1MBになる。市営住宅（約1,600棟）程度なら数MBに収まる想定。数万棟になると重くなるため、§4 の警告で止められるようにする。
- **ライセンス**：MapLibre GL JS は BSD-3。HTML内にライセンス表記を残す。
- **出典**：地理院タイルは出典の表示が必須。PLATEAUのデータを使う場合はその旨も表示する。
- **日本語**：列名・値に日本語や全角文字が入っても文字化けしないこと（UTF-8）。HTMLに出す文字はエスケープする。

## 8. 受け入れ条件

次をすべて満たせば v0.1 完了とする。確認は発注者が行う。

- [ ] 市営住宅3Dマップで使った住棟の建物データ（GeoPackage等）を読み込み、3D HTMLを書き出せる
- [ ] 書き出したHTMLをネット接続ありで開くと、背景地図の上に建物が正しい位置・高さで立ち上がる
- [ ] ネット接続なしで開いても、背景なしで建物が表示される
- [ ] QGISで分類（カテゴリ）の色分けをしたレイヤを書き出すと、同じ色で表示される
- [ ] 段階（グラデーション）の色分けでも同じ色で表示される
- [ ] 高さが空の地物が既定値で立ち上がり、半透明で区別される。補った件数が完了時に表示される
- [ ] 建物をクリックすると右側のパネルに詳細が出る
- [ ] 2D／3D切替、高さの強調、背景の切替が動く
- [ ] 「選択中の地物のみ」で書き出すと、選んだ建物だけが出る
- [ ] 平面直角座標系（例：第VI系）のレイヤでも位置がずれない
- [ ] 列名・値に日本語を含むレイヤで文字化けしない
- [ ] Edge と Chrome で表示できる
