about=This plugin has two main functions.
    (1) Connect facilities to buildings: match a facility layer (points, or site polygons for facilities with several buildings) to a building polygon layer such as PLATEAU bldg_Building, then review and correct the results on the map in a dock panel. Facilities that only have an address can first be turned into points with the offline "Location Reference Information" (位置参照情報, block level) published by MLIT Japan; the user downloads these zip files from MLIT and selects the folder. No online geocoding service is used.
    (2) 3D Publish: export a polygon layer as one self-contained HTML file in which buildings are extruded by a height field (e.g. measuredHeight) with MapLibre GL JS. Layer colours (single symbol / categorized), labels, surrounding buildings and boundary lines are carried over. The HTML can be opened in any browser and shared as a single file.
    Network use: the plugin itself makes no network requests. The exported HTML loads background map tiles from GSI Japan (cyberjapandata.gsi.go.jp) when it is opened in a browser; buildings are shown without a network. The optional "check this place on a map" tool opens Google Maps or GSI Maps in the system web browser only when the user clicks.
    MapLibre GL JS (BSD-3-Clause) is bundled in the vendor folder. The user interface is currently in Japanese.
    ---
    日本語：施設の点・敷地・住所を建物（PLATEAU など）にひも付けて地図上で確認・修正し、高さで立ち上げた 3D 地図を HTML 1ファイルに書き出します。住所から点を作る機能は、国土交通省の位置参照情報（街区レベル）の zip をご自身でダウンロードして使います（ネットの住所検索サービスは使いません）。
