# Building 3D HTML（QGISプラグイン）

QGISの面レイヤ（建物など）を、高さの列で立ち上げた **3D地図のHTML（1ファイル）** として書き出すプラグインです。
MapLibre GL JS をHTMLに埋め込むので、ネットがなくても建物は表示されます（背景の地理院タイルだけネットが必要）。

- 仕様書：[docs/spec_v0.1.md](docs/spec_v0.1.md)（今回の応募向けの変更は下の「進め方」を優先）
- 対応QGIS：3.28 以降（Qt5 / Qt6）

## フォルダ

| 場所 | 中身 |
| --- | --- |
| `building_3d_html/` | プラグイン本体（このフォルダをQGISのプラグインフォルダに入れる） |
| `building_3d_html/core/` | 画面と切り離した処理（レイヤ→GeoJSON、色分けの読み取り、HTML組み立て。照合などは後でここに足す） |
| `building_3d_html/templates/map3d.html` | 出力するHTMLのひな形 |
| `building_3d_html/vendor/` | MapLibre GL JS 4.7.1（BSD-3ライセンス） |
| `testdata/` | 試し用の建物データ（市営住宅の住棟、平面直角座標系 第VI系） |
| `tools/export_testdata.py` | QGISの画面を開かずにテストデータを書き出す確認用スクリプト |
| `tools/match_testdata.py` | 照合の確認用スクリプト（試し用の施設 `testdata/試し_施設.gpkg` も作る） |
| `testdata/試し_住所だけの施設.csv` | 住所から点を作る試し用（市営住宅の住宅名・区・所在地だけ） |
| `tools/geocode_testdata.py` | 住所から点を作る処理の確認用スクリプト（`街区データ/` に位置参照情報の zip を置いて使う） |
| `tools/adjust_testdata.py` | 照合の確認・調整パネルの確認用スクリプト（試し用の施設をコピーして使うので、元は変えない） |
| `tools/plateau_lod1_test.py` | PLATEAU の LOD1（立体の面の集まり）が、真上から見た1つの形になるかの確認用スクリプト |

## 自分のQGISに入れて試す

1. QGISを閉じる
2. エクスプローラーのアドレス欄に `%APPDATA%\QGIS\QGIS3\profiles\default\python\plugins` と入れて開く
3. このリポジトリの `building_3d_html` フォルダを、そこへ丸ごとコピーする
4. QGISを起動 →「プラグイン」→「プラグインの管理とインストール」→「インストール済」で **Building 3D HTML** にチェック
5. `testdata/shiei_jutaku_3d_trial.gpkg` をQGISにドラッグし、「市営住宅_住棟」レイヤを追加する
6. 「Web」メニュー →「Building 3D HTML」→「3D地図をHTMLに書き出す…」
7. 建物レイヤ＝市営住宅_住棟、高さの列＝高さm（自動で選ばれます）を確認して「書き出す」
8. 完了画面の「ブラウザで開く」で表示を確かめる

コードを直したあとは、コピーし直してQGISを再起動してください。

## PLATEAU の建物データで使うとき

1. 「PLATEAU QGIS Plugin」（国土交通省）を入れ、プロセシングツールボックスの「Project PLATEAU」→「PLATEAU 3D都市モデルを読み込む」で CityGML を読み込む
2. 建物（bldg_Building）のレイヤを、このプラグインの「建物レイヤ」または「周辺の建物」に選ぶ。高さの列は `measuredHeight` が自動で選ばれる
3. LOD1（立体）で読み込んでも、LOD0（平面）や「3Dデータを強制的に平面化する」で読み込んでも使える。立体は書き出すときに真上から見た1つの形にまとめる

## 進め方（PLATEAU AWARD 2026 応募向け）

仕様書 v0.1 から次を変更しています（仕様書より優先）。

- 色分けは「単一シンボル」と「分類（カテゴリ）」だけ対応。段階・ルールベースは後回し
- 設定の保存、件数の警告、ダークモード、海外データ・OpenStreetMap は後回し
- v0.1 の後に「点と建物の照合（簡易版）」→「周辺建物・計画建物（最小版）」の順で作る

### 決定事項（2026-10-09）

- 「北を上に固定」のため、マウスの右ドラッグ等での回転・傾けは止める。傾きは 2D／3D ボタンだけで切り替える
- 「ジオメトリが壊れている地物は除外」は、形が読めないもの（空・面でない・座標変換できない）だけを除外する。自己交差などの軽い不正は、表示できるので除外しない
- 色を「QGISのスタイルに合わせる」とき、QGIS で描かれない建物（レイヤパネルでチェックを外した分類、どの分類にも当たらない建物）は書き出さない。除外した件数は完了画面に出す

### 点と建物の照合（簡易版）の決定事項（2026-10-09）

- 当てはめ方：点が入っている建物。どれにも入っていなければ、決めた距離（既定 30m、ダイアログで変更可）以内でいちばん近い建物
- 結果：当たった建物の形に、建物の属性・施設（点）の属性・「判定」の列を付けた新しい面レイヤ。建物に当たらなかった点は別の点レイヤ
- 1つの建物に複数の施設が当たるのは複合施設としてありうるので、誤りとはしない。1棟1行にまとめ、施設の属性は「 / 」でつなぐ（施設の列は文字の列になる）。「施設数」の列を付ける
- 印を付けるのは「近くの建物で代用」と「建物なし」の2つ。建物の形（細長い・小さい）は問わない（住宅以外の公共施設も対象のため）

### 周辺建物・計画建物（最小版）の決定事項（2026-10-09）

- 周辺の建物：書き出す建物から決めた距離（既定 200m）以内だけを、灰色で立ち上げる。クリックはせず、高さ以外の属性は入れない。書き出す建物と同じ建物（周辺の建物の中の点が、書き出す建物に入るもの）は二重に描かないよう除く
- 計画建物：半透明の別色（#e4572e）で立ち上げ、「計画建物を表示」のオン・オフで今と計画後を見比べられる。クリックで名称・高さ・メモなど（fid を除く全列）を出す。レイヤ名に「計画」を含む面レイヤがあれば最初から選ぶ

### 背景地図・高さの強調（2026-10-10）

- 背景地図はダイアログで「淡色地図」「航空写真」をチェックで選び（既定は両方）、「最初に表示」も選べる（既定は淡色地図）。HTMLではチェックした背景と「なし」を切り替えられる
- 背景の濃さは背景ごとに覚える（初期値：淡色地図 35%、航空写真 85%）。出典は表示中の背景に合わせて変わる
- 高さの強調はダイアログで 1〜5倍（既定 1倍）。HTMLでは 1・3・5倍と、ダイアログで決めた倍率に切り替えられる

### 応募での見せ方と残りの作業（2026-10-14）

共同作業者の提案（応募準備チェックリスト素案）を受けて決めたこと。

- 応募では「施設データと PLATEAU の建物を正しく結び付ける」ことを中心に見せ、3D HTML はその出口として見せる。プラグインは1つのまま、「照合・調整」と「3D HTML 書き出し」の2つの機能にする
- 足す機能（この順で作る）
  1. 地図上で調整：「要確認」の施設を1件ずつ地図に出し、正しい建物をクリックで選び直す。施設の点の位置も動かせるようにする
  2. 住所だけの施設データ：住所から点を作る処理をプラグインに組み込む。ネットのサービスは使わず、国土交通省「位置参照情報」（オープンデータ）を先にダウンロードして、パソコンの中で探す（ネットにつなげにくい庁内のパソコンでも使えるように）
  3. （余裕があれば）3D HTML の検索・絞り込み
- 試し用の市営住宅データはオープンデータ（個人の応募で使ってよい）

### 地図上で調整の決定事項（2026-10-14）

- 照合のあと要確認（近くの建物で代用・建物なし）があれば、右に「照合の確認・調整」パネルを開く。一覧から1件ずつ選ぶと、施設の点（赤い丸）と当てた建物（オレンジの枠）に地図が寄る
- 直し方は2つ。「この建物でよい」は、当てた建物の中へ施設の点を動かす。「地図をクリックして直す」は、クリックした場所へ施設の点を動かす（建物の中をクリックすれば、その建物に当たる）。建物の選び直しと点の位置の修正を、1回のクリックで兼ねる
- 直すのは元の施設レイヤ。編集モードの中で動かすので、Ctrl+Z で取り消せ、残すときは QGIS の「編集内容を保存」を押す。CSV など編集できない形式は、GeoPackage に保存してから使ってもらう
- 結果のレイヤは自動では作り直さない。「照合し直して結果を更新」を押したときに、古い結果を外して新しい結果に入れ替える

### 住所から点を作るの決定事項（2026-10-14）

- 位置参照情報は「街区レベル」だけを使う。「〇丁目」までしか分からない住所は、その丁目の街区の代表点の平均に置く（「大字・町丁目レベル」のダウンロードはいらない）
- 位置参照情報は zip のまま1つのフォルダに入れ、ダイアログでそのフォルダを選ぶ（次からは覚えておく）。試しに使う大阪市24区の分は `街区データ/` に置き、リポジトリには入れない
- 住所の書き方の違い（全角・半角、「三丁目」「3丁目」「3-」、「大阪府」「大阪市」のあるなし、区の名前から始まる住所）は、比べる前にそろえる
- 結果は緯度経度の点レイヤ（一時レイヤ）。元の列に「住所の一致」（街区／町丁目／見つからない）と「一致した住所」を足す。見つからない施設も位置を空にして残す（照合では「位置が空」として数える）
- 市営住宅 1,868 棟の所在地で試すと、街区まで 1,858 件・丁目まで 10 件・見つからない 0 件。点は街区の代表の位置なので、照合すると建物の中は 625 件で、残りは要確認になる（地図上で調整して直す流れ）
